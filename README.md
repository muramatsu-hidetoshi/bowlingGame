# Bowling Game

C++ と DirectX 11 で制作した、Windows 向けの3Dボウリングゲームです。投球パワーを決め、揺れる照準に合わせてボールを投げます。ピンの衝突や倒れた本数の判定、カメラの追従、軌跡とエフェクトを実装しています。

## ゲームの流れ

1. タイトル画面で Enter キーを押してゲームを開始します。
2. P キーで投球パワーを決定します。パワーゲージは往復して変化します。
3. 照準が左右に揺れている間に O キーを押すと投球します。
4. ピンが止まると倒れた本数を判定し、ストライク、スペア、ガーターを通知します。
5. 4フレーム終了後にリザルト画面へ進みます。リザルト画面で Enter キーを押すとタイトルへ戻ります。

## 操作方法

| 操作 | キー |
| --- | --- |
| タイトル／リザルト画面の決定 | Enter |
| 投球パワーの決定 | P |
| ボールの発射 | O |
| ピンの再配置 | R |
| リザルト画面へ進む（開発用） | T |
| ゲーム終了 | Esc または Space |

## 主な機能

- 投球パワーと照準方向を使った投球操作
- ボールとピン、ピン同士の衝突処理
- ストライク、スペア、ガーターの判定と通知
- 投球中の追従カメラとステージ内カメラの切り替え
- ボールの軌跡や衝突時のパーティクル演出
- フレームごとの投球結果を表示するスコアボード
- タイトル、ゲーム、リザルト、ゲームオーバーのシーン管理

## 特に見ていただきたい技術要素

### 1. 投球を状態遷移として管理

`shot.cpp` では、投球操作を「パワー決定 → 照準 → 発射」の状態に分けています。パワーゲージの往復や照準の揺れは経過時間を使って更新し、発射要求をゲーム本体へ渡してからボールに力を加える構成です。

### 2. ボールとピンの衝突応答

`bowlingBall.cpp` と `PinManager.cpp` では、重力による移動、ステージとのAABB判定、ボールとピン・ピン同士の衝突を処理しています。AABBの重なりが最も浅い軸を使って位置を補正し、衝突方向と速度からピンへ力を伝えます。

### 3. 投球結果を確定するタイミング

`game.cpp` では、ボールが停止してからピンが落ち着くまで待って結果を集計します。投球前に残っていたピン数と、倒れたピンを取り除いた後の残数から倒した本数を求め、ストライク・スペア・ガーターの通知とスコアボードへ反映しています。

### 4. カメラと移動演出

`directionCamera.cpp` は投球中にボールを追うカメラを更新し、`camera_fixed.cpp` はステージ上の領域判定に応じて固定カメラを切り替えます。`trail.cpp` と `trailExplosion.cpp` では、ボールの移動軌跡と衝突時のパーティクル演出を描画しています。

### 5. DirectX 11の描画リソース管理

`direct3d.cpp`、`shader.cpp`、`shader3d.cpp`、`model.cpp` では、描画デバイスやシェーダー、定数バッファ、モデルの読み込み・描画・解放を分けて管理しています。3Dシーンを描画した後に深度テストを切り替えてUIを重ねる流れも確認できます。
